# FA-AGENT-UI-01 智能体模式保存修复

- 日期：2026-11-20；阶段：修复完成，等待最终完整门禁。
- 页面沿用现有控件，在创建及修改共用请求中传入 `agent_mode`；不改其他表单字段、布局及知识库绑定流程。
- 服务层创建时省略模式继续默认 passive，其他值严格限制为 active/passive；更新校验在版本递增及写库之前。更新省略字段保留原值，明确传入空值、null 或未知模式拒绝。

## 复现与修复证据

- 原页面真实 Vue/Element Plus 组件测试 4 失败、2 通过：创建及修改请求均缺少所选模式。补齐字段后 6 项通过，包含保存拒绝无成功提示、不跳转及保留选择。
- 真实 PostgreSQL 与管理 HTTP 接口复现未知模式 hybrid 被成功写入；服务层校验及更新解析修复后，非法值及类型返回 400，原模式与版本不变。
- 按生产装配分离管理与运行服务并预热缓存，再现 active/passive 双向修改后运行仍使用旧模式。切换到权威加载适配器后，真实生产运行 HTTP 入口选择正确生命周期；只有生命周期末端采用计数替身。
- 增加冷服务重载、省略模式、旧调用默认值、缺失及错误租户、已预热缓存下的数据库读取失败回归。租户隔离夹具显式启用 ModeOn 并在清理时恢复，不修改生产租户策略。
