## 引导与文档

菜单、标题和中英文引导同步业务用途。模块导览只针对实际下发且呈现的当前分组，使用顶部菜单、侧栏和内容区的真实目标；未登录、权限未知或目标缺失时不启动。CRM 与线索治理页面使用稳定内容锚点，避免受权限控制的入口缺失时产生空引导。

切换业务分组时销毁当前模块导览，同组内切页继续保留；全局导览不受模块切换影响。该问题已先复现再修复，并通过真实 Layout 路由测试和独立复核。

运行时和构建检查共用 i18n 资源清单，九种基础语言与业务文案分包分别登记。新业务文案提供中英文，其余语种沿用中文兜底；菜单标题仍逐项检查九语种完整性，资源清单校验防止分包漏接或误算为独立语言。

根目录和 `user-web/` 下的两份路由台账新增本轮实施记录，保留历史逐页点验记录。本轮没有增加或删除业务路由。
