## 修改与安全约束

- 生成脚本使用原生ESM文件导入，结果文件独立创建且 `wx` 禁止覆盖已有证据。
- 搜索框和重载按钮均来自当前语义快照，使用明确 `ref=` 操作，不枚举或批量点击。
- 等待真实 `extensions-item` 过滤完成且唯一名称匹配，再确认一个重载按钮。
- 按树形缩进定位目标最小卡片，独立读取版本与扩展ID，不混入相邻卡片。
- 重载后版本必须等于期望值，ID必须与重载前相同。成功证据返回后才用另一脚本清理该工具自有空间。
- 不打开渠道页面、不卸载扩展、不清存储、不接管Space54管理端登录交接。
