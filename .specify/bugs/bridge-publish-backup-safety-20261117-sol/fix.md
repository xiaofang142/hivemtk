# 扩展发布备份安全修复

来源：[assessment.md](assessment.md)。仅修改发布器备份与历史清理段。

- 不再自动删除第五份之外的回滚目录；默认保留全部用户历史证据。
- 备份目录独占创建，同名路径在安装同步之前拒绝，既有证据不覆盖。
- 逐项复制到新目录，`force:false`、`errorOnExist:true`。失败的部分备份保留供排查，不主动删除。
- 固定加载目录、扩展ID、版本/ZIP/线上地址预检及原地同步策略不变。

真实CLI合成测试先复现删除旧备份和覆盖同名目录。最初实现错误地对已经独占创建的目录整体复制，随后改为逐项复制；没有放宽测试。验证见[test.md](test.md)。未操作本机真实加载目录或重新加载扩展。
