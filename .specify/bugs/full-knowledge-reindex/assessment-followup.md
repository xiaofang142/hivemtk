# Assessment Follow-up: 持久向量与尝试次数

- Date: 2026-11-20
- Parent: [assessment.md](assessment.md)
- Verdict: valid；继续原 FA-13 修复范围。

产品文档检索以 PostgreSQL 的分段向量为权威。显式重建写入现有向量与来源字段，再完成文档状态；不新增可选内存 `BuildIndex` 调用，该调用会替换同产品其他文档的索引。原评估中的索引构建失败在此对应持久向量写入失败，已用真实数据库注入覆盖。

唯一清单还要求可查询的重试计数。原模型没有此字段；新增回归先观察到 `reindex_attempts` 缺失，再增加 `ReindexAttempts`。字段表示累计尝试次数，首次为 1、首次重试为 2，经文档详情与列表 JSON 可查询。启动模型迁移已登记该表，无须引入另一套迁移执行器。

游标同时捕获 `(created_at,id)` 上界与 `MaxID`，排除调用开始后自增的新 ID，包括回填较早创建时间的新文档。此机制不承诺识别起始时仍未提交、但已分配较小 ID 的事务；批次也不锁定并发删除或修改创建时间的文档。该并发边界写入修复与测试报告。
