# FA-AGENT-UI-02 · 修复记录

- 日期：2026-11-20
- 范围：编辑页绑定读取保护；无后端生产代码、表结构、配置、依赖及路由变更。

## 实现

绑定使用独立读取状态、来源智能体 ID、已读快照及请求代次。绑定读取成功且来源一致后才开放选择。未知、读取中、失败或响应格式不合法时，普通字段仍可保存，但不发送绑定替换；详情响应的兼容字段不能充当已读证据。读取失败以持久说明提示重试，不再被解释为空集合。

主记录请求去除 `kb_ids`。已成功读取但未改选择时同样不替换，防止普通保存覆盖另一编辑者的新绑定。显式选择的 ID 规范为字符串，保存开始时捕获本次快照；只有已读且确实改变时才调用独立替换接口。清空非空绑定须在任何写入之前确认，取消不会保存主记录或绑定。选择改变后禁止重载，避免重试抹掉用户操作。

晚到的成功或失败响应必须通过请求代次与来源校验；路由切换和卸载使旧请求失效。说明与清空确认覆盖现有九种语言。保留页面结构和其他字段行为。

## 已运行验证

- 原真实 Vue/Element Plus 组件红灯：14 例失败，直接观察普通保存仍夹带空 `kb_ids`、全量替换及旧读取覆盖。
- 初轮修复：本项 14 例与模式持久化 6 例共 20 项通过；新增边界覆盖后再执行最终验证。
- 真 PostgreSQL 测试通过：绑定读取故障后仅改名称保留原 KB/version；并发者明确改绑后普通更新保留新绑定；明确清空后实际 `resolveFAQKB` 消费者返回空。此为知识库/答案缓存选择路径，不冒充所有 FAQ/SOP 内容检索。
- ego 浏览器以本地合成接口逐元素验证：读取 503 后改名不发送绑定写入；重试读回原选择；清空取消不写任何接口；明确确认后才发送空集合替换，重新编辑读回真实空集合。未操作生产数据或外发消息。

## 边界

FA-AGENT-UI-03 的两个写请求部分失败及恢复协议另项处理，本项不把现有绑定写入失败的告警描述为事务保证。主动修改绑定时的服务端版本冲突协议未在本次引入；普通字段保存则完全不触碰绑定。最终全量检查、构建及上线证据分别记录在测试报告和生产拓扑台账。
