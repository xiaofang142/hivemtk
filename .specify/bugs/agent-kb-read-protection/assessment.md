# FA-AGENT-UI-02 · 知识库绑定读取失败保护

- 日期：2026-11-20
- 判定：valid；真实组件原实现 14 例全部失败，复现读取失败后隐式清空、未改也替换及旧响应覆盖。
- 范围：智能体编辑页绑定读取、选择与普通字段保存；FA-AGENT-UI-03 的部分写入失败协议另项处理。

## 根因与关闭条件

`Edit.vue` 把绑定读取异常和无法识别的响应都转换为空集合；保存普通字段时又无条件调用全量替换。仓储的空集合替换会真实删除所有绑定。详情响应的旧 `kb_ids` 字段不能代替独立绑定接口的权威快照。

区分未知、读取中、失败及已知空集合。未成功读取或未改选择时只保存普通字段，不发送绑定替换，也不在主记录请求中夹带 `kb_ids`。成功读取后的清空操作须在写入前明确确认。重试、晚到响应、路由切换及卸载不能覆盖当前选择。

## 方案论证

采用页面局部读取状态、来源智能体 ID、已读快照与请求代次；只有来源相同、读取成功且选择确实改变时才允许替换。未知/失败时禁用选择器并显示可重试说明，保留普通字段保存能力。统一字符串 ID，防止数值与字符串比较造成伪变更。保留现有页面结构，新增说明覆盖现有九种语言。

拒绝“失败按空保存”和“每次普通保存都替换旧快照”：前者删除现有绑定，后者覆盖其他会话新增的绑定。对已修改选择禁用重载，避免无意丢失用户更改；服务端版本冲突协议不在本次读取故障修复中引入。

## 验证计划

真实 Vue/Element Plus 组件通过 API 边界替身覆盖失败、真空、未改、重试、显式清空确认/取消、并发晚到响应、卸载与创建。真实 PostgreSQL 测试核对普通字段保存后的绑定保持，以及 `SmartCSOrchestrator.resolveFAQKB` 实际绑定消费者的 KB ID/Version 随明确替换变化。该消费者是知识库/答案缓存选择路径，不把它描述成所有 FAQ/SOP 内容检索；旧 FAQEntry 仅有 AgentID，不能虚构 KB 外键。浏览器使用本地受控接口逐元素验收，不改生产数据、不外发消息。
