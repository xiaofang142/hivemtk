- **Slug**: release-quality-gate-regressions

- **Assessment**: [根因与实施范围](assessment.md)

## Changes

- 修正八处 Go 格式、HTTP 响应体关闭的错误处理及三处内部错误字符串；删除无调用的机器人解析包装，保留在用解密、消息处理与事件分支。
- 微信客服客户端先安装渠道默认 BaseURL，再应用调用方选项，保留本地模拟上游覆盖能力。
- 两个不执行查询的仓储装配方法改为包级构造函数，保留数据库句柄与 nil 语义；实际查询继续接收原请求 context。渠道路由服务文件去掉冗余后缀。
- 根配置样例明确已有平台心跳默认值与设备信标空租户白名单拒收语义；子目录样例补心跳开关，不新增运行时配置。
- 修正十处历史文档断链；缺失的历史制品明确标注未保留，跨独立仓路径改为路径说明，六份旧收敛报告链接现存 partial 验证，不改变其结论。
- 工作流控制器成功夹具使用合法 trigger/log 图及 source/target 边，检查创建结果后再解析响应；新增五种非法图拒绝且零持久化用例，保留服务端校验。
- 对固定 Slack 验签时间窗口登记具体安全理由，不将防重放边界开放为运维旋钮，不修改验签实现或扫描规则。
- 九份语言包各删除同一个已无消费点的长度校验死词条，保持词条集合一致，不修改 i18n 棘轮基线或新增虚假调用。
- 定时任务租户门只按仓库内相对路径排除隐藏目录和依赖目录，避免原生 worktree 上层 `.local` 导致漏扫。既有牙齿测试补两项覆盖隐藏上层仍发现违规、内部排除规则不变。

- `TestNewClient_DefaultAndOverrideURL` 修复前确认默认 URL 为空，修复后微信客服包测试通过。
- 原完整 Go 测试的五项工作流控制器失败在独立 Go 缓存下再次复现；更新夹具后该控制器测试集及新增非法图子例通过。

- 新仓储装配测试首次误用了无参构造器，编译失败；已更正为现有显式数据库注入构造器，未改生产构造行为。最终复测结果记入 test.md。
