# FA-AGENT-TOOL-03 工具列表分页评估

- 日期：2026-11-20；结论：有效，源码确认，待组件红灯复现。
- 症状：工具超过默认 20 条后没有翻页入口，页面将当前页长度显示为总数。
- 链路：`user-web/src/api/aiTool.js` 原样传递查询；`user-server/internal/controller/ai_tool_config_ctrl.go` 已接收 page/page_size，默认 1/20、上限 100；列表返回 list/total。`ToolList.vue` 的 loadTools 不传分页，忽略 total；模板没有 el-pagination。
- 根因：前端缺少服务端分页状态和入口，统计口径未区分筛选总数与本页启禁数；异步响应也没有新旧请求隔离。

## 方案论证

采用现有 Element Plus 服务端分页：初始 20，允许 20/50/100；筛选、重置和每页条数改变回第一页，刷新保留当前页。总数使用响应 total，本页启禁数明确标注。最新请求独占行、统计、错误及 loading 状态。末页因并发删除越界时按新 total 回到有效页，恢复重查有次数上限；仍不一致明确报错。读取失败清除可操作旧行并显示可重试错误，不能冒充空结果。

备选一：一次拉取全部工具。放弃，接口存在上限，不能保证 101 条以上完整；增加接口和内存压力。备选二：本地分页。放弃，只能切分已取得的第一页，保留漏项。无需新增 Go 接口、路由、生产假数据或引导入口。
