# 自动触达 P0 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:executing-plans to implement this plan (no subagents in this repo, rule 0b). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地触达 P0 五项，让 browser-automation×JEV 跑起社交平台留言/评论触达。

**Architecture:** JEV action 空间补 TYPE_TEXT；账号池＋封号熔断进 executor；用户级去重键进写台账；活动预算＋时间线可观测；触达回执落库。全部默认关闭走 env/配置门控，保持向后兼容。

**Tech Stack:** Go（five-layer：Router→Controller→Service→Repository→Model），LLM dispatcher `ScenarioJevChoice`，Chrome MV3 扩展，Postgres。

**Spec:** `docs/superpowers/specs/2026-09-30-outreach-product-design.md`
