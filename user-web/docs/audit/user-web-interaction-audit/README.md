本轮以 85 个路由模块为静态范围，包含 241 条带组件业务路由、4 条重定向。完整覆盖表见 [routes.md](routes.md)。源码检查、组件测试和浏览器受控数据验证分别记录，不互相替代。

## 环境与覆盖边界

- 真实前端：`http://127.0.0.1:8211/`，已打开登录首屏。
- 本地受控入口：`http://127.0.0.1:18215/`，挂载真实 Vue 页面组件；请求由本地合成数据应答，不访问真实业务和外部渠道。

- 未执行真实删除、消息发送、支付、生产发布、Git 提交或推送。保留原有 `docs/verification/api-list.md` 修改。
