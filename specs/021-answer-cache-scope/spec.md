# 配置与执行能力受约束的答案缓存

状态：Specified；用户授权自主实施。风控与完整正确回答先于命中率。

## 用户场景与验收

1. 同租户、同渠道、同代理/模型/提示/嵌入版本的纯知识新问，可复用经过正常链路生成的答案；配置变化必须回源。
2. 可能使用工具、动态资产提示、脚本/流程、内容审核或用户个性化的路径不能被最终答案缓存跳过。拒答、转人工、降级、卡片/操作承诺不入此缓存。
3. 已答追问、NO_REPLY、投诉/人工保护、会话事务、限次、发前人工锁维持现有硬门。
4. 生成期间知识或配置变化不得把旧答案贴成新版本；旁路写入有界且故障可观测，不能阻塞回答。

## 功能要求

- FR001：键为不超过64字符的不可逆配置摘要，包含租户、渠道/账号、代理全部输出配置、KB灰度版本、嵌入配置与调度器配置、紧凑回答与卡片能力策略。不得在日志/存储键暴露凭证。
- FR002：完整身份与稳定能力证明缺失时不用最终答案快路；代理工具列表为空不意味着运行时无工具。
- FR003：只缓存完整、非降级、非工具/卡片/审核/脚本/流程输出；使用当前代理实际置信阈值。查询与生成前后配置一致，知识版本复核一致。
- FR004：每个编排器至多4个后台缓存写入，2秒上下文预算；满容量可观测跳过，下一次正常生成仍可重建，绝不影响业务回答。
- FR005：原手动低层 v1 缓存及 KBAnswerVersionFor 灰度接口兼容；生产键不借旧未证明范围的行。按新生产键准备的正常命中、追问旁路及知识版本失效仍真实验证。
- FR006：不降低模型/工具/租户/人工/质量门槛；模型路由选择保持原配置，响应缓存另修配置范围。

## 非目标与限制

不宣称任意自然语言答案已自动证明事实完备；缺少证据的动态执行链保守不用最终答案缓存。此实现不是线上收益证据，真实对照与全量门禁前不得 Converged。
